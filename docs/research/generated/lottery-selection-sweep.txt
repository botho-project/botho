### Track 1 — redistribution (Δgini vs a burn baseline)

Collect-and-redistribute over 10 years. Initial Gini 0.7773; burn baseline (collect demurrage, redistribute nothing) Gini 0.7525. Δgini = burn − rule (higher = more equalizing). Recovery = Δgini ÷ ClusterWeighted's Δgini.

### Track 2 — Sybil resistance (ticket share under splitting)

Attacker: one 100000-BTH whale coin at factor 5.745x, fragmented into K fresh equal coins, measured against a fixed reference population of 100 holders (which still contains idle whales, so the population max-fee stays high). The metric is the attacker's **share of total lottery weight** (bounded in [0,1] — a splitter can never exceed 100% of tickets). Split-invariant = the share barely moves under a 1000-way split (the ClusterWeighted property). The demurrage the whale sheds is churn-invariant, so the only real cost of the split is (K−1)×base_fee = 249.8 BTH at K=1000.

### CT-compatibility & incremental leakage

| rule | CT-clean | reason | leakage beyond ADR-0006-public |
|------|:--------:|--------|--------------------------------|
| Uniform | yes | reads nothing about value (equal weight) | none |
| ClusterWeighted | **no** | weight ∝ hidden value → needs a ZK sort over amounts | N/A (not CT-compatible) |
| FeeInverse | yes | reads only the public fee (already public under ADR 0006) | none beyond the already-public fee |
| CirculationGated | yes | reads only public creation age / circulation | none (creation heights already public) |
| Hybrid(fee×circ) | yes | reads only public fee + public age | none beyond the already-public fee + age |
